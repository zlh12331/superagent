## 1. 功能概述

B5 多线叙事同步是 AI/Agent 网文写作软件的核心叙事管理模块，负责在多线叙事（如主线 + 支线 + 暗线）的创作过程中实现数据同步、上下文切换和一致性维护。模块采用"数据管理独立、检查委托执行"的架构，B5 自身负责叙事线数据的存储、状态管理和上下文切换，检查逻辑委托给 ReviewerAgent 执行。

模块的核心设计理念是"切换无损、读者无感"——作者在不同叙事线之间切换时，系统能自动保存当前进度、加载目标线的上下文、生成交接摘要，确保创作连续性不受切换影响。通过 12 个核心机制（M1-M12）和 4 个辅助机制（S1-S4），覆盖叙事线的全生命周期管理。

### 核心设计原则

- **数据管理独立**：叙事线数据（存档点、状态、依赖关系等）由 B5 独立管理，不依赖 ReviewerAgent
- **检查委托执行**：跨线一致性检查由 ReviewerAgent 调用 B5 数据后执行，B5 不直接执行检查
- **切换无损**：叙事线切换时自动保存/加载，切换延迟 < 900ms（保存 < 100ms + 加载 < 500ms + 恢复摘要 < 300ms）
- **读者无感**：通过交接文档自动生成（M2），确保切换后读者体验连续
- **渐进自动化**：三级自动化策略（S4），从手动到全自动，适配不同作者的使用习惯

### 机制分层总览

| 层级 | 机制 | 说明 |
|------|------|------|
| 数据层 | M1 叙事线存档点系统 | 解决上下文切换，自动保存/恢复 |
| AI 层 | M2 交接文档自动生成 | 读者体验连续性保障 |
| Agent 层 | M3 叙事线 AI 助手 | 辅助叙事线管理 |
| 算法层 | M4 全局时间轴引擎 | 多线时间对齐 |
| 数据层 | M5 角色知识背包 | 信息隔离，角色只知该知的信息 |
| 算法层 | M6 叙事线依赖图 | 线间依赖关系管理 |
| 状态层 | M7 叙事线生命周期 | 叙事线状态管理 |
| 算法层 | M8 线拓扑变更 | 叙事线结构变更管理 |

## 4. 业务规则

### 4.1 叙事线存档点规则

- **BR-B5-01**：每次切换叙事线时自动创建存档点，存档点包含编辑位置、上下文快照、待处理事项
- **BR-B5-02**：存档点保存操作 < 100ms，使用增量保存（仅保存变更部分）
- **BR-B5-03**：每条叙事线最多保留 50 个自动存档点，超出后按 LRU 策略淘汰
- **BR-B5-04**：手动创建的命名存档点不受数量限制，且不会被自动淘汰
- **BR-B5-05**：恢复存档点时，如当前内容有未保存变更，提示用户确认

### 4.2 全局时间轴规则

- **BR-B5-06**：每条叙事线有独立的时间线，时间格式支持绝对时间（年/月/日）和相对时间（第 N 天）
- **BR-B5-07**：当某线的时间推进时，系统自动检查其他活跃线的时间是否需要同步
- **BR-B5-08**：时间冲突检测规则：同一角色在同一绝对时间不能出现在两条不同的叙事线中（除非有意设计）
- **BR-B5-09**：时间冲突预警级别：critical（角色时间冲突）→ high（事件时间矛盾）→ medium（时间线模糊）

### 4.3 角色知识背包规则

- **BR-B5-10**：每个角色在每条叙事线中有独立的知识背包，初始为空
- **BR-B5-11**：角色在某线中获知新信息后，仅更新该线的背包，不影响其他线
- **BR-B5-12**：写作时 WriterAgent 注入的角色上下文仅包含当前线的知识背包内容
- **BR-B5-13**：知识背包内容可手动编辑，支持批量导入/导出
- **BR-B5-14**：角色跨线出现时（如从 A 线到 B 线），系统提示是否将 A 线的部分知识迁移到 B 线

### 4.4 叙事线生命周期规则

- **BR-B5-15**：叙事线创建时默认为 planned 状态，首次写作时自动转为 active
- **BR-B5-16**：active 状态的叙事线超过 30 天未更新时，系统建议转为 paused
- **BR-B5-17**：paused 状态的叙事线超过 90 天未恢复时，系统建议转为 archived
- **BR-B5-18**：合并操作（merging）需要两条线均为 active 状态
- **BR-B5-19**：archived 状态的叙事线保留所有历史数据，支持重新激活

### 4.5 叙事线依赖规则

- **BR-B5-20**：循环依赖（A→B→C→A）不允许创建，系统自动检测并拒绝
- **BR-B5-21**：删除被依赖的叙事线时，系统提示受影响的下游线列表
- **BR-B5-22**：依赖关系变更时，自动重新计算受影响线的进度和状态

### 4.6 交接文档规则

- **BR-B5-23**：交接文档在切换时自动生成，包含前文摘要（≤ 200 字）、当前进度、待处理事项、情感状态
- **BR-B5-24**：交接文档生成时间 < 300ms（使用缓存的前文摘要，仅更新变更部分）
- **BR-B5-25**：交接文档注入 WriterAgent 上下文，作为切换后的写作参考

### 4.7 自动化策略规则

- **BR-B5-26**：默认自动化等级为 L0（手动），作者可按操作类型独立调整
- **BR-B5-27**：L1（半自动）模式下，系统推荐操作需作者确认后执行
- **BR-B5-28**：L2（全自动）模式下，自动操作记录日志，作者可事后审查和撤销
- **BR-B5-29**：自动化等级提升需作者主动操作，系统不会自动提升

### 4.8 线切换性能规则

- **BR-B5-30**：保存当前线 < 100ms
- **BR-B5-31**：加载目标线 < 500ms
- **BR-B5-32**：恢复交接摘要 < 300ms
- **BR-B5-33**：切换总延迟 < 900ms（不含网络延迟）

| 叙事线状态 | 更新后的叙事线状态 | JSON |
| 冲突检测结果 | 叙事线间的依赖冲突 | JSON |

### 存储要求

| 存储位置 | 数据内容 | 生命周期 |
|----------|----------|----------|
| Supabase `narrative_lines` 表 | 叙事线定义和状态 | 永久 |
| Supabase `narrative_dependencies` 表 | 叙事线依赖关系（DAG） | 永久 |
| Neo4j（Edge Function 代理） | 叙事线间人物交叉引用图 | 永久 |
