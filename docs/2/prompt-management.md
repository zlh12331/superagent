# Prompt 模板管理 - 功能需求文档

## 1. 功能概述

- **所属模块**：手动 LLM 模式
- **功能描述**：管理所有 Agent 的 prompt 模板，支持查看、编辑、版本管理和预览完整组装后的 prompt。让作者持续优化 prompt 效果。
- **优先级**：P1
- **页面路由**：/settings/prompts

---

## 2. 验收标准 (Acceptance Criteria)

### AC-1: 模板列表查看

- **Given** 用户进入 Prompt 模板管理页面
- **When** 页面加载完成
- **Then** 显示所有 Agent 的 prompt 模板列表（Orchestrator、WriterAgent、ReviewerAgent、StyleAgent、WorldBuilderAgent、CharacterAgent、OutlineAgent、InspirationAgent、ContextRouter 等），每个模板显示名称、最后修改时间、版本号

### AC-2: 模板编辑

- **Given** 用户点击某个 Agent 的模板
- **When** 进入编辑页面
- **Then** 显示模板编辑器（代码编辑器风格），支持模板语法的实时渲染预览（变量占位符高亮、格式化展示）

### AC-3: 版本保存

- **Given** 用户修改了模板内容
- **When** 点击"保存新版本"
- **Then** 系统保存新版本，自动递增版本号，保留历史版本

### AC-4: 版本对比

- **Given** 用户查看某个模板的版本历史
- **When** 选择两个版本进行对比
- **Then** 以 diff 视图展示两个版本的差异

### AC-5: 版本回滚

- **Given** 用户对当前版本不满意
- **When** 点击"回滚到此版本"
- **Then** 模板内容恢复为所选版本，当前版本归档

### AC-6: 完整 Prompt 预览

- **Given** 用户在模板编辑页
- **When** 点击"预览完整 prompt"
- **Then** 系统基于当前项目数据组装完整 prompt（包含上下文注入），展示最终效果

### AC-7: 从调用历史导入

- **Given** 用户在 LLM 调用历史中发现效果好的 prompt
- **When** 点击"保存为模板"
- **Then** 该 prompt 被导入为对应 Agent 的新模板版本

---

## 3. 业务规则 (Business Rules)

| 编号 | 规则描述 |
|------|----------|
| BR-1 | 每个模板最多保留 50 个历史版本，超出时自动清理最早的版本 |
| BR-2 | 模板编辑采用代码编辑器风格（等宽字体、语法高亮），支持变量占位符（如 `{{character_name}}`） |
| BR-3 | 预览功能使用当前项目的真实数据组装，不使用模拟数据 |
| BR-4 | 系统内置默认模板，用户修改后自动创建第一个自定义版本 |

---

## 4. 用户故事 (User Stories)

| 编号 | 用户故事 |
|------|----------|
| US-1 | 作为作者，我希望查看和编辑所有 Agent 的 prompt 模板，以便持续优化 prompt 效果 |
| US-2 | 作为作者，我希望保存模板的多个版本并对比差异，以便找到最佳 prompt |
| US-3 | 作为作者，我希望预览完整组装后的 prompt，以便了解实际发送给 LLM 的内容 |
| US-4 | 作为作者，我希望从调用历史中导入效果好的 prompt 作为模板，以便快速复用 |

---

## 5. 界面要求 (UI Requirements)

### 5.1 页面布局

- **左侧**：Agent 模板列表（树形结构，按 Agent 分组）
- **右侧**：模板编辑器（代码编辑器风格）+ 版本历史面板
- **底部**：预览按钮、保存按钮、版本对比按钮

### 5.2 各区域说明

| 区域 | 说明 |
|------|------|
| Agent 模板列表 | 树形结构展示所有 Agent 的模板，支持展开/折叠，显示模板名称和版本号 |
| 模板编辑器 | 代码编辑器风格，等宽字体、语法高亮，支持变量占位符（如 `{{character_name}}`） |
| 版本历史面板 | 显示模板的历史版本列表，支持版本对比和回滚操作 |
| 底部操作栏 | 包含预览、保存新版本、版本对比等操作按钮 |

---

## 6. 数据要求 (Data Requirements)

### 6.1 输入数据

| 数据项 | 说明 | 来源 |
|--------|------|------|
| Agent 类型 | 当前编辑的 Agent 标识 | 模板列表选择 |
| 模板内容 | 模板的 prompt 文本内容 | 编辑器输入 |
| 版本信息 | 版本号、修改备注等 | 用户输入 |

### 6.2 输出数据

| 数据项 | 说明 | 格式 |
|--------|------|------|
| 保存的模板版本 | 包含模板内容和版本元数据 | JSON |

### 6.3 存储要求

| 存储位置 | 数据内容 | 生命周期 |
|----------|----------|----------|
| Supabase `prompt_templates` 表 | 模板基本信息（Agent 类型、当前版本号等） | 永久 |
| Supabase `prompt_template_versions` 表 | 模板版本历史（内容、版本号、时间戳等） | 永久 |
