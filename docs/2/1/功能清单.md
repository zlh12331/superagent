# 📋 功能清单 — AI/Agent 网文写作助手

> **说明**：基于所有 PRD 文档整理，适配 **Python 个人项目 + DeepSeek 模型**。
> **架构**：Python CLI → SQLite 本地存储
> **模型策略**：`deepseek-v4-flash`（默认，便宜快速）+ `deepseek-v4-pro`（复杂任务手动切换）
> **数据存储**：SQLite + JSON 文件辅助

---

## 🔴 Phase 1：核心基础设施（P0 必须项）

### 1.1 DeepSeek API 调用
| 编号 | 功能 | 说明 |
|------|------|------|
| LLM-01 | 对话补全封装 | 调 DeepSeek `/chat/completions`，支持流式/非流式 |
| LLM-02 | JSON 输出模式 | 结构化数据用 `response_format: {"type": "json_object"}` |
| LLM-03 | 流式输出 | 正文生成时流式展示 |
| LLM-04 | 多轮对话管理 | 手动拼接 `messages`，支持追问迭代 |
| LLM-05 | Pro/Flash 切换 | 默认 Flash，复杂任务手动切 Pro（思考模式 `enabled`） |

### 1.2 数据存储层
| 编号 | 功能 | 说明 |
|------|------|------|
| DB-01 | SQLite 数据库初始化 | 统一存储所有项目数据 |
| DB-02 | 作品管理 | 创建/打开/删除/切换作品 |
| DB-03 | 章节数据表 | 章节内容、字数、元数据 |
| DB-04 | 角色/实体数据表 | 角色/地点/物品结构化数据 |
| DB-05 | 设定数据表 | 世界观、力量体系、阵营等设定 |
| DB-06 | 配置数据表 | 项目设置、模板、用户偏好 |
| DB-07 | JSON 文件辅助 | 大纲、伏笔链等复杂结构 |

### 1.3 命令行界面基础
| 编号 | 功能 | 说明 |
|------|------|------|
| CLI-01 | 主菜单 | 项目管理、切换、进入各功能模块 |
| CLI-02 | 交互式操作 | 命令行选择/输入，不需要复杂 TUI |

## 🔵 Phase 2：核心写作功能（P0 必须项）

### 2.1 B1 大纲系统
| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| B1-01 | 角色弧线定义 | 角色起点→终点→变化过程 | P0 |
| B1-02 | 情感曲线设计 | 每角色 0-100 情感曲线 | P0 |
| B1-03 | 事件→情感映射 | 事件对角色情感影响 | P0 |
| B1-04 | 三级大纲（卷纲/章纲） | 卷目标+关键事件→章场景/字数/节奏/伏笔 | P0 |
| B1-05 | 章纲伏笔计划 | 伏笔描述/类型/回收章节 | P1 |
| B1-06 | 大纲→写作衔接 | WriterAgent 注入情感目标/节奏/伏笔 | P0 |
| B1-07 | 大纲-正文联动 | 章纲变更标记正文不一致 | P1 |

### 2.2 智能写作（WriterAgent）
| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| WR-01 | 正文续写 | 基于大纲+上下文生成内容，流式输出 | P0 |
| WR-02 | 改写/扩写/缩写 | 对指定文本操作 | P0 |
| WR-03 | 多轮迭代 | 不满意追问修改 | P0 |
| WR-04 | 上下文注入 | 写作时注入当前章情感目标/节奏/伏笔/角色状态 | P0 |
| WR-05 | 自动保存 | 每次生成结果自动保存 SQLite | P0 |

### 2.3 B2 一致性检测（简化为靠 LLM 审查）
| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| B2-01 | LLM 一致性审查 | 写完一章后让 DeepSeek 检查设定/逻辑/角色矛盾 | P0 |
| B2-02 | 结果分级展示 | critical/high/medium/low | P0 |
| B2-03 | 按角色重要性加权 | 主角问题优先级高 | P1 |

> **简化说明**：原设计 17 种检测机制太复杂，个人用直接靠 LLM 审查一轮就够了，算法层的硬规则检查意义不大。

### 2.4 B3 因果链（合并到一致性审查）
| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| B3-01 | 因果链检查 | 合并到 LLM 一致性审查中一并检查 | P1 |

> **简化说明**：因果链不单独成模块，和 B2 合并，审查时让 DeepSeek 顺带检查。

## 🟢 Phase 3：增强功能（P1-P2）

### 3.1 B7 伏笔管理
| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| B7-01 | 伏笔 CRUD | 手动添加/编辑/删除伏笔 | P1 |
| B7-02 | 伏笔 5 状态机 | 埋设→活跃→暗示→回收→完成 | P1 |
| B7-03 | 伏笔分类 | 道具/人物/情节/世界观/误导 | P1 |
| B7-04 | 回收提醒 | 长间隔未回收伏笔预警 | P1 |
| B7-05 | 伏笔总览视图 | 列表展示所有伏笔状态 | P1 |

> **简化说明**：去掉 AI 自动识别（P2 太复杂）、去掉依赖链 DAG、去掉密度监控仪表盘，保留手动管理+回收提醒。

### 3.2 B8 节奏控制（简化版）
| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| B8-01 | 5 维节奏分析 | 叙事速度/对话比/动作比/情感强度/信息密度 | P1 |
| B8-02 | Pacing 5 值 | slow/medium/buildup/fast/climax | P1 |
| B8-03 | 章纲节奏 vs 实际节奏对比 | 偏差检测 | P2 |

> **简化说明**：去掉 8 种模板、7 种题材配置、6 项检测器（D1-D4）、RhythmAdvisor，只保留基础分析功能。

### 3.3 角色系统（简化版）
| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| CH-01 | 角色属性管理 | 姓名/外貌/性格/能力/背景 | P0 |
| CH-02 | 角色状态追踪 | 当前情绪/位置/关系变化 | P1 |
| CH-03 | 角色关系网 | 角色间关系（师徒/敌对/恋人等） | P1 |
| CH-04 | 角色记忆记录 | 重要事件记录，供写作时注入 | P1 |

> **简化说明**：去掉独立 Agent 实例、五层记忆架构、react_to() 接口、智能遗忘、三层分离等。个人用不需要这么复杂的角色模拟，存好角色信息和关系就够了。

### 3.4 B6 角色状态桥梁（合并到角色系统）
| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| B6-01 | 角色状态持久化 | 角色情感/位置/关系永久存储 | P0 |

> **简化说明**：合并到角色系统，不单独成模块。

### 3.5 B4 风格一致性（简化版）
| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| B4-01 | 风格宪法定义 | 用文本定义全书风格基准 | P2 |
| B4-02 | AI 味检测 | 写完章节后让 DeepSeek 检查 AI 味 | P2 |

> **简化说明**：去掉 50 维统计引擎、词汇控制、5 级降级、漂移追踪等，留最核心的。

### 3.6 B5 多线叙事（视需要启用）
| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| B5-01 | 叙事线管理 | 创建主线/支线/暗线 | P2 |
| B5-02 | 章节归属线 | 每章标记所属叙事线 | P2 |
| B5-03 | 切换上下文 | 切换线时展示前文摘要 | P2 |

> **简化说明**：去掉存档点系统、时间轴引擎、知识背包、生命周期管理、依赖图等。个人写网文一般就 1-2 条线，轻量管理就够了。

### 3.7 知识库 + 搜索（简化版）
| 编号 | 功能 | 说明 | 优先级 |
|------|------|------|--------|
| KS-01 | 关键词搜索 | SQLite LIKE 搜索章节/角色/设定 | P1 |
| KS-02 | 实体索引 | 角色/地点/物品快速查找 | P1 |
| KS-03 | 世界观设定库 | 力量体系/地理/阵营结构化管理 | P1 |
| KS-04 | 外部资料导入 | txt/md 文件导入参考 | P2 |

> **简化说明**：去掉 FTS5 全文搜索（LIKE 够用）、去掉知识快照、去掉混合搜索。

## 🎯 DeepSeek 适配

- **默认模型**: `deepseek-v4-flash`（便宜快速，用于续写/改写/大纲生成等大部分场景）
- **复杂任务**: 手动切换 `deepseek-v4-pro`（思考模式 `enabled`，`reasoning_effort="high"`，用于深入审查）
- **Base URL**: `https://api.deepseek.com`
- **JSON 模式**: `response_format: {"type": "json_object"}`
