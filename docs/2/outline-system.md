## 1. 功能概述

B1 大纲系统是 AI/Agent 网文写作软件的核心创作骨架模块。系统采用"角色弧线先行"理念，从角色要经历的变化出发构建大纲，通过情感曲线设计、事件-情感映射、铺垫检查算法和大纲预演引擎，确保故事结构合理、情感节奏到位。

系统提供三级大纲体系（全书粗纲 → 卷纲 → 章纲），配合三栏布局的大纲编辑器，支持拖拽排序、批量编辑、版本对比等交互能力。大纲与正文深度联动，章纲变更自动标记已有正文为"不一致"，写作时实时向 WriterAgent 注入情感目标、节奏建议和伏笔推进信息。

此外，大纲系统与 B5 多线叙事系统集成，支持从卷纲的叙事线计划自动创建 B5 叙事线。

### 核心设计原则

- **角色弧线先行**：大纲从"角色要经历什么变化"开始，而非从事件开始
- **情感驱动结构**：每个事件标注对角色的情感影响，确保铺垫到位
- **三级约束体系**：全书粗纲（硬约束）→ 卷纲（强约束）→ 章纲（中约束）
- **大纲-正文联动**：章纲变更自动检测与已有正文的不一致
- **AI 辅助不替代**：预演引擎标注"AI 编辑建议，仅供参考"

## 4. 业务规则

### 4.1 角色弧线规则

- **BR-01**：大纲创建时必须先定义至少 1 个核心角色的弧线（起点 → 终点 → 变化过程）
- **BR-02**：核心角色弧线定义包含：角色 ID、起始状态、目标状态、关键转折点列表
- **BR-03**：情感曲线值域为 0-100，0 为极度低落，100 为极度高涨
- **BR-04**：情感曲线支持手动编辑和 AI 辅助生成两种模式

### 4.2 事件-情感映射规则

- **BR-05**：每个事件必须标注对至少 1 个相关角色的影响
- **BR-06**：角色影响映射包含：情感变化方向（上升/下降/持平）、变化幅度（1-10）、性格变化描述、铺垫需求标记
- **BR-07**：铺垫需求标记为 true 的事件，必须在后续章节中有对应的铺垫事件

### 4.3 铺垫检查规则

- **BR-08**：角色重大变化（情感变化幅度 ≥ 7）至少需要 3 个铺垫事件
- **BR-09**：铺垫事件的情感强度应呈递增趋势（允许偶尔回落，但整体趋势向上）
- **BR-10**：铺垫事件间隔不应超过 5 章（否则读者可能遗忘）
- **BR-11**：铺垫检查算法输出格式：`{ character_id, change_event, setup_events: [], missing_setups: [], intensity_trend: "increasing"|"flat"|"decreasing", max_gap: number }`

### 4.4 大纲预演规则

- **BR-12**：预演引擎所有输出必须标注"AI 编辑建议，仅供参考"
- **BR-13**：预演评估维度及权重：情感曲线起伏（0.25）、铺垫到位率（0.25）、节奏低迷段（0.15）、伏笔间距（0.15）、角色平衡（0.20）
- **BR-14**：节奏低迷段定义为连续 3 章以上节奏值低于 0.3

### 4.5 三级大纲约束规则

- **BR-15**：全书粗纲为硬约束，章纲不得违反粗纲定义的核心设定和主线走向
- **BR-16**：卷纲为强约束，章纲不得违反卷纲定义的分卷目标和关键事件
- **BR-17**：章纲为中约束，写作时可灵活调整，但需记录偏差
- **BR-18**：章纲节奏字段使用 5 值枚举：`slow` / `medium` / `buildup` / `fast` / `climax`

### 4.6 大纲-正文联动规则

- **BR-19**：章纲变更后，系统自动扫描已有正文，检测不一致项
- **BR-20**：不一致标记包含：变更类型（新增/修改/删除）、涉及字段、影响范围（章节列表）
- **BR-21**：作者可手动确认"已处理"来消除不一致标记

### 4.7 叙事线集成规则

- **BR-22**：卷纲 line_plan 变更时自动同步 B5 叙事线（创建/更新/删除）
- **BR-23**：章纲所属叙事线变更时自动更新 B5 章节归属
- **BR-24**：叙事线间依赖关系从卷纲自动推断，作者可手动调整
